## 推荐演示顺序

### 1. 管理员端

登录后建议按以下顺序演示：

- `全局监控`
  - 展示“当天 / 近7天 / 近30天”切换
  - 说明页面会展示“当前展示区间”
  - 若当前系统日期晚于数据最新日期，系统会自动回退到最近有数据区间
- `行为分析`
  - 展示行为趋势、留存分析、运动偏好、时段活跃分布
  - 展示三个排行榜：运动时长、卡路里消耗、减重效果
- `教练管理`
  - 查看教练列表
- `学员管理`
  - 查看学员与教练分配情况

### 2. 教练端

- `计划管理`
